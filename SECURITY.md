# Security Policy

## Reporting a vulnerability

Please report security vulnerabilities privately through the **Report a vulnerability** option on the arkanaOS Security tab. Do not post vulnerability details in public issues or discussions. Include the affected arkanaOS release or build, steps to reproduce the issue, its impact, and any suggested mitigation.

The maintainers will review reports and coordinate a fix or mitigation before sharing technical details publicly. Security fixes depend on upstream availability where arkanaOS includes third-party software.

## Supported releases

Support starts on the publication date of each release or build. The support windows are:

- Nightly builds: 7 days
- Alpha releases: 2 weeks
- Beta releases: 7 weeks
- Stable releases: 10 months

After a build reaches the end of its support window, upgrade to a currently supported build to receive further fixes.
